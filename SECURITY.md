# Security policy

## Supported versions

Bug fixes and security patches are provided only for the most recent version
of SafeRedirect.

## Announcements

[Security advisories are published on GitHub](https://github.com/scoville/safe_redirect/security).

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues,
discussions, or pull requests.

[Disclose them privately via GitHub](https://github.com/scoville/safe_redirect/security/advisories/new).
